fin-rag Architecture

RAG 金融知识库问答系统 — 索引管道 + 融合检索 + 引用校验

📥 Ingestion Pipeline

  • • 支持 9 种文件格式 (md/csv/xlsx/pdf/java/xml/py/txt)
  • • 大文件智能摘要 (CSV/XLSX > 1MB 仅取前6行)
  • • 元数据自动提取: 领域/产品代码/渠道/文档类型
  • • 三级分块: 1024/512/256 tokens, overlap=80
  • • 双写存储: Qdrant 向量 + SimpleDocumentStore BM25

📤 QA Pipeline

  • • 三入口: CLI (fin-rag ask) / FastAPI (:8010) / Gradio (:7860)
  • • 融合检索: 向量 + BM25 → Reciprocal Rank Fusion
  • • 短查询自适应阈值 (0.15/0.20/0.30)
  • • 引用校验: 编号检查 + 产品代码幻觉检测
  • • 降级重试: no_sources/empty_answer → 无阈值重试

⚙ Infrastructure

  • • Qdrant 向量库 (dim=768, BAAI/bge-base-zh-v1.5)
  • • LLM: OpenAI 兼容接口 (DeepSeek 等)
  • • 本地 Embedding HTTP 服务 (:8001)
  • • 配置: YAML + 环境变量 FIN_RAG_* 覆盖
  • • 结构化 JSON 日志 (LLM 请求延迟/错误追踪)
